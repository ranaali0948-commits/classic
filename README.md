# Vallée du Kashmir — démonstration web

Site vitrine React + Vite pour Vallée du Kashmir, restaurant indien et pakistanais situé au 10 Rue d’Odessa, Paris 14e.

## Développement

```bash
npm install
npm run dev
```

Vérifications avant livraison :

```bash
npm run typecheck
npm run lint
npm run build
```

Les photographies définitives doivent être ajoutées selon les indications de `public/images/README.md`.
