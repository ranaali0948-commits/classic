- `restaurant/restaurant-interior-02.webp` — salle ou décoration, format paysage
- `restaurant/dining-room.webp` — salle dressée, format paysage
- `dishes/butter-chicken.webp` — format paysage ou carré
- `dishes/mixed-grill.webp` — format paysage
- `dishes/biryani.webp` — format paysage ou carré
